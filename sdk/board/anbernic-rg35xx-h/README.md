# Anbernic RG35XX H

Allwinner H700 / quad Cortex-A53 handheld with a Mali-G31 (panfrost) GPU. **Definition only** - described in the tree but
not built or verified here. A real build needs a kernel carrying this device's
device tree (sun50i-h700-anbernic-rg35xx-h-rev6-panel) and driver patches; shared Allwinner H700 / quad Cortex-A53 options live in
`sdk/board/allwinner-h700/`.
