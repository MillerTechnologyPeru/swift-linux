# Retroid Pocket Nova

Qualcomm QCS8550 / Snapdragon 8 Gen 2 handheld with a Adreno 740 (freedreno/turnip) GPU. **Definition only** - described in the tree but
not built or verified here. A real build needs a kernel carrying this device's
device tree (qcs8550-retroidpocket-rpnova) and driver patches; shared Qualcomm QCS8550 / Snapdragon 8 Gen 2 options live in
`sdk/board/qualcomm-sm8550/`.
