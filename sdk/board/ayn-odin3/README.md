# AYN Odin 3

Qualcomm SM8750 / Snapdragon 8 Elite handheld with a Adreno 830 (freedreno/turnip) GPU. **Definition only** - described in the tree but
not built or verified here. A real build needs a kernel carrying this device's
device tree (cq8725s-ayn-odin3) and driver patches; shared Qualcomm SM8750 / Snapdragon 8 Elite options live in
`sdk/board/qualcomm-sm8750/`.
