# Mangmi Air X (MQ66)

Qualcomm SM6115 / Snapdragon 662 handheld with a Adreno 610 (freedreno/turnip) GPU. **Definition only** - described in the tree but
not built or verified here. A real build needs a kernel carrying this device's
device tree (sm6115-mangmi-air-x-mq66) and driver patches; shared Qualcomm SM6115 / Snapdragon 662 options live in
`sdk/board/qualcomm-sm6115/`.
