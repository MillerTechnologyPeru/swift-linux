# Rockchip RK3399 (2x A72 + 4x A53, Mali-T860) patches

Shared kernel patches for Rockchip RK3399 (2x A72 + 4x A53, Mali-T860) Chromebooks (BR2_GLOBAL_PATCH_DIR, stacked
before each device's patches/). linux/*.patch patch the kernel. Known needs
from mainline-Chromebook work go here (display/BT bring-up quirks).
