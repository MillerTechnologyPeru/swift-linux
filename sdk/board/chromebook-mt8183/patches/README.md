# MediaTek MT8183 (4x A73 + 4x A53, Mali-G72) patches

Shared kernel patches for MediaTek MT8183 (4x A73 + 4x A53, Mali-G72) Chromebooks (BR2_GLOBAL_PATCH_DIR, stacked
before each device's patches/). linux/*.patch patch the kernel. Known needs
from mainline-Chromebook work go here (display/BT bring-up quirks).
