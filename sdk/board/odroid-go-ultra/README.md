# Odroid Go Ultra

Amlogic S922X / 4x A73 + 2x A53 handheld with a Mali-G52 (panfrost) GPU. **Definition only** - described in the tree but
not built or verified here. A real build needs a kernel carrying this device's
device tree (meson-g12b-odroid-go-ultra) and driver patches; shared Amlogic S922X / 4x A73 + 2x A53 options live in
`sdk/board/amlogic-s922x/`.
