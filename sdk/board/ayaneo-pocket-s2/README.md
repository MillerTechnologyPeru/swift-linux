# Ayaneo Pocket S2

Qualcomm SM8650 / Snapdragon 8 Gen 3 handheld with a Adreno 750 (freedreno/turnip) GPU. **Definition only** - described in the tree but
not built or verified here. A real build needs a kernel carrying this device's
device tree (sm8650-ayaneo-ps2) and driver patches; shared Qualcomm SM8650 / Snapdragon 8 Gen 3 options live in
`sdk/board/qualcomm-sm8650/`.
