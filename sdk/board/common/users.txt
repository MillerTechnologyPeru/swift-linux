# Default non-root user for Swift Linux.
# Format: <username> <uid> <group> <gid> <password> <home> <shell> <groups> <comment>
#   password "=1234"   -> clear-text password "1234"
#   group "video"      -> access to the seatd socket (seatd -g video), which
#                         grants the Weston session DRM/input without root.
#   group "input"      -> /dev/input/event* (udev's 50-udev-default.rules
#                         assigns them GROUP="input"). The compositor gets
#                         input through seatd, but SDL2 reads game
#                         controllers from evdev directly, so the session
#                         user needs it for gamepads in EmulationStation
#                         and games. Buildroot's skeleton has no such
#                         group, hence the group-only line below.
- - input -1 * - - - -
user 1000 user 1000 =1234 /home/user /bin/sh video,tty,audio,dialout,wheel,input Default User
