# Anbernic RG DS

Rockchip RK3566 / quad Cortex-A55 handheld with a Mali-G52 (panfrost) GPU. **Definition only** - described in the tree but
not built or verified here. A real build needs a kernel carrying this device's
device tree (rk3568-anbernic-rg-ds) and driver patches; shared Rockchip RK3566 / quad Cortex-A55 options live in
`sdk/board/rockchip-rk3566/`.
