# Qualcomm SC7180 (Kryo 468, Adreno 618) patches

Shared kernel patches for Qualcomm SC7180 (Kryo 468, Adreno 618) Chromebooks (BR2_GLOBAL_PATCH_DIR, stacked
before each device's patches/). linux/*.patch patch the kernel. Known needs
from mainline-Chromebook work go here (display/BT bring-up quirks).
