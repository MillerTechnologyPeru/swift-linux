# Retroid Pocket Mini

Qualcomm SM8250 / Snapdragon 865 handheld with a Adreno 650 (freedreno/turnip) GPU. **Definition only** - described in the tree but
not built or verified here. A real build needs a kernel carrying this device's
device tree (sm8250-retroidpocket-rpmini) and driver patches; shared Qualcomm SM8250 / Snapdragon 865 options live in
`sdk/board/qualcomm-sm8250/`.
