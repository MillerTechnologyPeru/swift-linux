# Gameforce Ace

Rockchip RK3588S / 4x A76 + 4x A55 handheld with a Mali-G610 (panfrost) GPU. **Definition only** - described in the tree but
not built or verified here. A real build needs a kernel carrying this device's
device tree (rk3588s-gameforce-ace) and driver patches; shared Rockchip RK3588S / 4x A76 + 4x A55 options live in
`sdk/board/rockchip-rk3588/`.
